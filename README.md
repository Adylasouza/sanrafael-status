Sistema de Monitoreo - Hospital San Rafael

[cite_start]Este proyecto consiste en un portal web técnico e informativo que permite visualizar el estado de salud y disponibilidad en tiempo real de los sistemas de información, servidores y máquinas virtuales del **Hospital San Rafael**, tomando inspiración funcional y visual de plataformas estándar de la industria (*Status Pages*)[cite: 294, 295, 413].
